Page 1: Kanban Board

- Columns: TO DO, DOING, DONE.

- Task Fields: Title, Description, Category, Start Date, Due Date, Complete Date, Responsible Person, Status.

- Responsible Persons: Predefined list (ID, Name).

- Categories: Select existing or add new.

- Operations: Create, Edit, Delete, Move (Drag & Drop or Button), Assign Person/Category, Date Management.

- Storage: Local Storage for persistence.

Page 2: Dashboard

- Summary Cards: Total Tasks, TO DO count, DOING count, DONE count, Overdue count.

- Task Status Chart: Pie or Doughnut (TO DO vs DOING vs DONE).

- Task Category Chart: Bar chart showing tasks per category.

Completion Performance Chart: Comparison of Early, On Time, and Late completions.
